# The 3 Checks

**Three decisions an AI fleet can't make for you. Run them before you spend the compute.**

From Episode 1 of *One Researcher, One Research Fleet* — [watch on YouTube](https://youtube.com/@OneResearchFleet).

📄 **[Download the 1-page PDF](three-checks.pdf)** (A4, printable, with fill-in lines)

---

## 1. Which question?

*When: before you start a project, or before you turn a result into a paper.*

- [ ] **Who actually cares?** Name a person, an industry, or a decision that depends on it.
- [ ] **If it works, what changes?**
- [ ] **Can I write a one-line title that makes someone want to read it?**

> **Fail any one → it's a foundation, not a headline.**

Method is credibility; it isn't the finding. Once you have a claim, let a cheap model attack it. Each time it survives, it gets narrower and harder to argue with.

```
My one-line title:        ______________________________
Who cares / what changes: ______________________________
```

## 2. Could it change my next decision?

*When: before every run — simulation, experiment, or overnight AI job.*

- [ ] **List the results that could come back.**
- [ ] **For each one, write what you would do differently.**
- [ ] **Compute, money and your attention are all limited. Which one is the bottleneck right now?**

> **No possible result changes what you do → don't run it. It's decoration.**

Run the funnel:

| Wide end | Survivors | Narrow end |
|---|---|---|
| cheap, fast checks on everything | expensive simulation | real experiment + your attention |

```
If the result is …   → I will …
______________________________
______________________________
Bottleneck this week: ________
```

## 3. Kill criteria first

*When: before you look at any result.*

- [ ] **Write down what would prove it, and what would kill it. Date it.**
- [ ] **Send the AI to find counter-examples, not to prove you right.**
- [ ] **Too clean, too confident, too good?** Trace it back to its inputs and assumptions before you believe it.

> **A result that good is a question, not an answer.**

AI makes trying cheap. It also makes you wrong faster, and more convincingly. What catches it is your judgment of what's physically possible.

```
It holds if:  ______________________________
It's dead if: ______________________________
Written on:   ____-__-__
```
