# One Researcher, One Research Fleet

Battle-tested notes from running a fleet of AI agents for engineering research: a dispatcher, short-lived workers, local models, cloud models, and plain scripts doing most of the work.

Each episode of the [YouTube series](https://youtube.com/@OneResearchFleet) is a real post-mortem: what broke, why, and how it was rebuilt. This repo holds what you can take away from each one.
